

## تحديث واجهة الإلغاء الجاري

بعد تثبيت بوابة runtime، تم تمرير `cancellationRequested` إلى `AgentPlanViewModel` وإظهاره في سطحي لوحة الوكيل:

- `AgentPlanContent` يعرض `Stopping` / `جارٍ الإيقاف` بلون التحذير.
- تتوقف نبضة التنفيذ أثناء الإلغاء حتى لا توحي بأن خطوات جديدة ما زالت تُنفذ.
- `AgentPlanOverlay` يعرض الحالة نفسها ولا يحولها إلى `Cancelled` قبل وصول الإلغاء النهائي.
- تمت إضافة موارد اللغة العربية والإنجليزية.

هذا فصل صحيح بين حالة الإلغاء الجاري والحالة النهائية، ولا يغيّر runtime أو يعلن نجاح الإلغاء قبل وصول `onGraphCancelled`.
