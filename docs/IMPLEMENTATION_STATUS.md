# حالة تنفيذ تحسينات AIRI

**تاريخ التحديث:** 13 أغسطس 2026
**نطاق الحالة:** نسخة العمل الكاملة في هذا المستودع، بعد تعديل المصدر والتحقق الساكن.
**قاعدة القراءة:** لا تعني كلمة «منفذ» أن ملف APK اجتاز البناء أو اختبار جهاز فعلي ما لم يذكر ذلك صراحة.

> تعذر تشغيل تجميع Kotlin في هذه البيئة لأن ملحق Android Gradle Plugin `8.2.2` غير موجود في الذاكرة المحلية، ولا يمكن لبيئة التنفيذ حالياً الوصول إلى مستودعات الإضافات. مرّ التحقق الساكن المرفق بنجاح، لكنه لا يحل محل البناء أو الاختبار على جهاز.

## اختبارات التحقق المنفذة

شُغّل `tools/verify_core_changes.py` ونجح في **23/23 فحصاً ساكناً**. يغطي الفحص ملكية الإلغاء، حراسة callbacks، سياسة قبول الذاكرة، نطاق البحث المتجهي، حدود RAG، ربط `/` و`@`، RTL، حذف الحساب، إيقاف الصوت، تهدئة كلمة التنبيه، نتائج وعمل WorkManager الفريد، PKCE، ملكية صوت الجلسة، تقطيع العربية، تنظيف الوسوم، وتماثل مفاتيح الموارد في اللغات الأربع.

## ما يجب عمله قبل دمج أو نشر إصدار

| أولوية | إجراء مطلوب | سبب |
|---|---|---|
| P0 | تشغيل `:app:assembleDebug` و`:app:testDebugUnitTest` في بيئة تصل إلى Google Maven | لم يتحقق تجميع Kotlin في هذه البيئة. |
| P0 | اختبار إلغاء نص وصورة، `/`، `@`، وحذف حساب تجريبي ومعرف Room على جهاز فعلي | المصدر فقط لا يثبت دورة حياة Android أو Room أو Firebase. |
| P1 | اختبار WorkManager في وضع Doze وبعد إعادة تشغيل الجهاز | ضمان الجدولة الدائمة وحالة النتائج. |
| P1 | اختبار RTL واللغة العربية مع السمة الفاتحة والداكنة وAMOLED | التوافق المرئي وإتاحة الوصول لا يثبتان بالتحليل الساكن. |
| P1 | تنفيذ أو إخفاء إعدادات realtime cloud voice حتى يتصل نقل PCM end-to-end | يمنع وعداً بميزة لا تعمل تشغيلياً. |
