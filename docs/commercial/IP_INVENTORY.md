# AIRI Core IP Inventory

> هذا الجرد يصف نطاقات المصدر والمراجعة المطلوبة. لا يثبت ملكية قانونية ولا ينقل أي حق.

| فئة الأصل | الموقع أو المصدر | الحالة الحالية | إجراء قبل صفقة أو توزيع |
|---|---|---|---|
| كود AIRI التطبيقـي | `app/src/main/java/com/airi/assistant/` | ضمن مستودع AIRI؛ يتطلب المشتري التحقق من سلسلة الملكية والموظفين/المتعاقدين. | مراجعة Git history واتفاقيات الإسناد والملكية. |
| موارد Android وترجمات | `app/src/main/res/` | جزء من التطبيق؛ قد تحوي أسماء/شعارات أو نصوص تحتاج قرار branding. | مراجعة العلامة والأصول وحقوق الترجمة. |
| كود native | `app/src/main/cpp/` وllama.cpp المدمج | طرف ثالث/مستورد بحسب المصدر الفعلي. | توثيق المصدر/revision والإشعارات والترخيص. |
| تبعيات Gradle | `gradle/libs.versions.toml` و`app/build.gradle.kts` | تبعيات معلنة؛ الرسم المتعدي غير مؤرشف في هذا المستند. | إنشاء SBOM/raster متعدٍ وإشعارات لكل إصدار. |
| نماذج محلية | تنزيلات/تخزين داخلي خارج Git غالباً | لا ينبغي افتراض أنها ملك AIRI أو قابلة لإعادة التوزيع. | جرد model-by-model مع الترخيص والوزن والمصدر. |
| أصول صوت | Vosk/Porcupine/OpenWakeWord وملفات keyword/model اختيارية | قد تملك شروطاً مستقلة عن runtime. | جمع مصدر كل asset وشروط استخدامه وتوزيعه. |
| مفاتيح وملفات خدمة | متغيرات بيئة/أسرار CI/حسابات سحابية | ليست ملكية فكرية قابلة للنقل مع Git. | تدوير واعتماد حسابات المشتري وinventory للـsecrets. |
| بيانات مستخدم | Room/مرفقات/مزود سحابي وفق إعداد المستخدم | ليست أصلاً قابلاً للبيع بلا أساس قانوني وموافقة. | سياسة نقل بيانات وخصوصية منفصلة وموافقة عند الاقتضاء. |

## قواعد نقل المنتج

1. لا تُدرج مفاتيح API أو مفاتيح توقيع أو OAuth client secrets في تسليم المصدر.
2. لا تُدرج نماذج أو datasets أو أصول صوت من دون مصدر وترخيص وقرار توزيع مكتوب.
3. لا تُنسب ملكية لمكتبة أو نموذج طرف ثالث في التسويق أو الوثائق.
4. تُنقل إعدادات CI وrelease كقوالب، ثم يعيد المشتري إنشاء أسراره وحساباته.
5. تُحفظ attribution notices ونسخة dependency graph مع كل artifact إنتاجي.

## عناصر تحتاج تحققاً خارجياً

- سلسلة ملكية كود المصدر والعقود ذات الصلة.
- رخص النماذج والأصول التي قد يختارها المستخدمون أو فريق التوزيع.
- حقوق العلامات التجارية، الأيقونات، الخطوط، ومواد التسويق.
- متطلبات نقل/معالجة بيانات المستخدم حسب السوق المستهدف.
