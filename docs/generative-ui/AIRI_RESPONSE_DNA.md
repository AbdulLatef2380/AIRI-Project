# AIRI Response DNA

## الهدف

لا يعرض AIRI كل إجابة بالطريقة نفسها. يمر كل رد عبر عقد تركيب موحد يقرأ نية الطلب، حالة المحادثة، حالة البث، المرفقات، نتائج الأدوات، المصادر البعيدة، والملفات الناتجة، ثم يختار مسار عرض أصليًا ومحدودًا.

هذا ليس قالبًا بصريًا جديدًا ولا تنفيذًا لكود يولده النموذج. النموذج ينتج المحتوى، بينما AIRI يملك قرار العرض والتحقق والتفاعل.

## المسار الكامل

```text
User intent + conversation state
        ↓
AgentLoop admission and capability evidence
        ↓
Tool / connector / sandbox / artifact results
        ↓
ResponseRequestProfile
        ↓
ConversationResponseCompositionPlanner
        ↓
ResponseComposition
        ↓
ContentAwareMessageRenderer / GenerativeUiCompiler
        ↓
Native Compose surfaces + trace + next action
```

## بصمات الرد

| البصمة | الاستخدام | الترتيب الافتراضي |
|---|---|---|
| Conversation | السؤال المباشر | مقدمة، إجابة، خطوة تالية |
| Explanation | الشرح والتعليم | مقدمة، إجابة، خطوة تالية |
| Comparison | المقارنات | مقدمة، جدول، دليل، خطوة تالية |
| Document / Artifact | الملفات والتقارير | مقدمة، بطاقة artifact، مرفقات، خطوة تالية |
| Code | البرمجة | مقدمة، code viewer، شرح، خطوة تالية |
| Symbolic | المعادلات والرموز | مقدمة، كتلة LTR، شرح |
| Evaluation | التقييم والمراجعة | مقدمة، دليل، جدول، مخاطر، خطوة تالية |
| Data | المؤشرات والبيانات | مقدمة، دليل، مخطط، مصادر |
| Map | الطرق والمواقع | مقدمة، خريطة/مسار، عدم يقين، مصادر |
| Media | صورة أو صوت أو فيديو | مقدمة، media surface، metadata، خطوة تالية |
| Workspace | موقع أو تطبيق أو لعبة أو عرض | مقدمة، artifact/media، إجراءات، trace |

## قواعد الاستقرار

- لا يظهر `airi-ui` أثناء البث قبل اكتمال المخطط والتحقق من JSON.
- لا يسمح المخطط بمسارات أو URLs أو HTML أو JavaScript أو Kotlin من النموذج.
- الأفعال التفاعلية تعود إلى `ConversationExecutionCoordinator` ولا تستدعي موصلًا أو Terminal مباشرة.
- نتائج الأدوات والمصادر البعيدة لا تختلط مع نص AIRI النهائي؛ تعرض كأدلة منفصلة.
- المرفقات والملفات والوسائط تبقى مرتبطة بسياق الجلسة وملكيتها، ولا يكفي ذكر اسمها لإثبات إنشائها.
- المحادثات الطويلة تحافظ على الهوية والمكونات التفاعلية وتعرض سجل التنفيذ بدل تكرار كل التفاصيل في الفقاعة.
- عند غياب الدليل أو عدم اكتمال capability، يعرض AIRI الحالة غير المتحققة بدل ادعاء نجاح.

## الاختبار

يجب أن يغطي الاختبار النقي على الأقل السؤال المباشر، المقارنة مع مصادر، ملفًا مع مرفق، البث التدريجي، إنشاء الوسائط، وإنشاء مساحة عمل. أما اختبارات Compose وAndroid والأدلة الفعلية فتظل جزءًا من بوابات CI ولا تُستبدل بنجاح الاختبارات النقية.
