# AIRI Core Commercial Overview

## التموضع الأساسي

**AIRI Core هو منصة وكيل ذكاء اصطناعي محلية أولاً لنظام Android**: يجمع نموذجاً محلياً قابلاً للتشغيل دون اتصال مع مسارات سحابية اختيارية، وذاكرة مقصودة، ومهارات، وموصلات، ومرفقات، وصوت، وطبقات خصوصية قابلة للفحص.

هذا التموضع يخدم ثلاثة مسارات متوافقة:

| المسار | القيمة الممكنة | ما هو موجود في المصدر |
|---|---|---|
| منتج Android مباشر | مساعد هجين يتجنب حصر المستخدم في مزود واحد. | UI، محادثة، نماذج محلية/سحابية، صوت، ذاكرة، مرفقات. |
| ترخيص تقني | طبقات تنفيذ، نماذج، ذاكرة، مهارات وموصلات يمكن دمجها في منتج آخر. | حدود تنفيذ وذاكرة وموصلات موثقة، وليست SDK عامة بعد. |
| white-label/OEM | نقطة انطلاق لتغيير الاسم والواجهة والإعدادات مع إبقاء المحرك. | طبقات Compose والموارد والإعدادات قابلة للفصل؛ يلزم عمل branding منظم قبل التسليم لشريك. |

## ما يميز AIRI عملياً

1. **محلي أولاً:** مسار `llama.cpp` محلي ومسار cloud اختياري، بدلاً من افتراض السحابة كحالة وحيدة.
2. **ذاكرة مقصودة:** لا تُرقى الرسائل عشوائياً إلى حقائق طويلة المدى، وتُعزل الاستعادة بالجلسة.
3. **حدود بيانات واضحة:** مرفقات خاصة بالتطبيق، حذف عمر حياة، وبيانات RAG/المرفقات غير موثوقة.
4. **وكيل قابل للإيقاف:** جيل تنفيذ مملوك يوقف callbacks المتأخرة بعد الإلغاء.
5. **توسعة منضبطة:** المهارة workflow، والموصل قدرة وصول؛ لا يخلط التصميم بينهما.

## حالة الإثبات

| المجال | الحالة | الدليل |
|---|---|---|
| بناء وإصدارات Android | **BUILD_VERIFIED** | CI يبني Debug وRelease وAAB ويغلف JNI. |
| اختبارات instrumentation | **RUNTIME_VERIFIED** | Android CI يشغّل AndroidTest على محاكي. |
| بنية الوكيل والخصوصية | **SOURCE_VERIFIED** | المتحقق الثابت وفاحص الأمان وتوثيق الحدود. |
| أداء الأجهزة والصوت الحقيقي | **NOT_RUNTIME_VERIFIED** | يحتاج جهازاً ونماذج وأذونات حقيقية. |
| مزود/موصل/ OAuth إنتاجي | **EXTERNAL** | يحتاج credentials ونطاقات وشروط مزود فعلية. |
| رأي قانوني أو توافق ترخيص نهائي | **EXTERNAL** | يحتاج مراجعة قانونية للتبعيات والنماذج والأصول قبل بيع أو توزيع واسع. |

## ما لا تدّعيه هذه الحزمة

لا تمثل AIRI خدمة SaaS مؤسسية مكتملة، ولا SDK عامة منشورة، ولا نظام اشتراكات أو paywall، ولا موافقة قانونية على كل ترخيص تابع. الوثائق ترفع قابلية الفحص والنقل، لكنها لا تستبدل التدقيق القانوني أو الأمني الخارجي.
