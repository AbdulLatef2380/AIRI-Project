# AIRI Core Security Boundaries

## حدود لا يجوز تجاوزها بلا تصميم واختبار

| الحد | القاعدة | دليل المراجعة عند التغيير |
|---|---|---|
| UI → تنفيذ وكيل | الواجهة ترسل intent، ولا تنفذ فعلاً خارجياً مباشراً. | اختبار الحالة، مسار إلغاء، وpermission check. |
| مرفق → تخزين | لا يحتفظ بURI منتقي النظام؛ ينسخ إلى `filesDir` بعد تحقق النوع والحجم. | اختبار حجم/نوع/duplicate وتنظيف عند الحذف. |
| RAG أو نص مرفق → prompt | المحتوى بيانات غير موثوقة ومحدودة الحجم. | تحقق من delimiter والحدود وعدم تحويله إلى tool instruction. |
| نموذج → موصل/أداة | النموذج يقترح؛ طبقة السياسة والصلاحية تقرر التنفيذ. | مسار موافقة/منع، ونطاق موصل مصرح به. |
| مزود سحابي → أسرار | المفاتيح في تخزين آمن؛ `CloudErrorMapper` يصنف جسم HTTP محلياً ولا يعيده في الخطأ أو diagnostics، لذلك لا يكشف السجل النص أو المفتاح الخام. | فاحص أمان، اختبار mapper/store، ومراجعة logs. |
| طلب التنفيذ → مزود سحابي | في Balanced، لا يمر `prompt` أو `systemPrompt` أو `conversationHistory` إلى adapter قبل `PrivacyGuard`؛ يستبدل الحارس المسارات وURIs وcredentials وIP الخاص وGPS وIMEI/serial وcontext الإتاحة، ويسجل الفئات فقط. | `PrivacyGuardTest` + مراجعة `HybridOrchestrator.applyPrivacyGate`. |
| جلسة → ملفات | حذف الجلسة ينظف metadata وملفاتها الخاصة فقط. | تحقق من اسم الملف ومنع path traversal. |
| تنفيذ قديم → UI | لا تقبل callbacks من جيل ملغى أو قديم. | اختبار `ExecutionGenerationGate`. |

## قائمة مراجعة إضافة قدرة جديدة

1. عيّن مالك البيانات ومدة الاحتفاظ بها قبل كتابة UI.
2. صنف أي مدخل خارجي كغير موثوق.
3. أضف حدود حجم/وقت/تكرار/إلغاء عندما يتعامل المسار مع ملفات أو شبكة أو native.
4. لا تعرض خطأ المزود الخام للمستخدم ولا تسجله كاملاً.
5. أضف اختباراً للحالة السلبية وفحصاً ثابتاً إذا كان الضمان معماريّاً.
6. حدّث `DATA_FLOW.md` و`THREAT_MODEL.md` إذا تغير ما يُخزن أو ما يغادر الجهاز.

## إجراءات يمنع تنفيذها تلقائياً

| الإجراء | المعالجة المطلوبة |
|---|---|
| إرسال بيانات لموصل خارجي جديد | إعداد صريح، نطاق صلاحية، وموافقة مستخدم ملائمة. |
| فتح رابط أو تشغيل محتوى تنزيل | اعتبار المصدر غير موثوق والتحقق من طبيعة الفعل قبل التنفيذ. |
| ترقية مرفق إلى ذاكرة طويلة المدى | لا يحدث إلا عبر admission وطلب أو نية صريحة. |
| حذف مسار ملف من metadata | يقتصر على مجلد التطبيق واسم محقق. |
| تفعيل cleartext traffic أو مكون Android مصدّر | مراجعة تهديد موثقة وفحص Manifest. |

## التحقق الآلي المرتبط

```bash
python3 tools/security_scan.py
python3 tools/verify_core_changes.py
python3 scripts/airi_core_health.py
```

هذه الأدوات مؤشرات مصدر وCI؛ لا تحل محل اختبار اختراق أو مراجعة قانونية أو اعتماد مزود خارجي.
