# ملاحظات مرجعية لبرنامج AIRI Agent OS

تدعم هذه الملاحظات **اتجاه التصميم** فقط؛ لا تعني أن AIRI يكرر منتجاً خارجياً أو يعلن توافقاً معه.

| المصدر | الملاحظة القابلة للتحقق | أثرها على AIRI |
|---|---|---|
| [Open WebUI Workspace](https://docs.openwebui.com/features/workspace/) | يصف مساحة عمل مبنية من Models وKnowledge وPrompts وSkills وTools؛ المكونات اختيارية وقابلة للتركيب، وتوجد حدود صلاحيات للاستيراد والتصدير. | تثبيت AIRI Workspace كتركيب صريح من عناصر لها ملكية وسياق وصلاحيات، لا كشاشات منفصلة. |
| [Claude Code CLI reference](https://docs.anthropic.com/en/docs/claude-code/cli-usage) | يوثق جلسات قابلة للاستئناف، أوضاعاً وعمليات تشخيص، وإدارة MCP وتحديثاً صريحاً وسجلات للعمليات الخلفية. | يبرر أولوية durable tasks والـaudit/diagnostics وواجهة CLI منفصلة مستقبلاً، مع عدم افتراض أنها منفذة في AIRI. |
| [Manus My Computer page](https://manus.im/blog/manus-my-computer-desktop) | لم تكن الصفحة متاحة أثناء هذه المراجعة بسبب رسالة صيانة؛ لا تستخدم هذه المراجعة أي claim تفصيلي منها كدليل. | يؤجل الاستناد إلى تفاصيل Manus إلى تحقق جديد عند عودة الصفحة، ولا يغير حدود AIRI الأمنية. |

> المبدأ التصميمي المعتمد: **AIRI بيئة وكيل شخصية محلية أولاً**. كل قدرة جديدة يجب أن ترتبط بمالك بيانات وسياق وصلاحيات وحدث تدقيق ومهمة دائمة عندما يكون ذلك مناسباً.
