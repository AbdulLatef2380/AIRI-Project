# مراجع إعدادات سلسلة بناء AIRI

- **Android 16 SDK setup**: تتطلب Android 16 استخدام Android Gradle Plugin 8.9.0-rc01 أو أحدث، ثم `compileSdk = 36` و`targetSdk = 36` عند الاستعداد لتغييرات سلوك Android 16.
  المصدر: <https://developer.android.com/about/versions/16/setup-sdk>

- **Android Gradle Plugin 8.10.1**: يدعم API 36، ويتطلب Gradle 8.11.1 وJDK 17.
  المصدر: <https://developer.android.com/build/releases/agp-8-10-0-release-notes>

- **Google Play target API requirement**: اعتباراً من 31 أغسطس 2026، تتطلب التطبيقات والتحديثات الجديدة Android 16 / API 36 أو أعلى للإرسال إلى Google Play.
  المصدر: <https://developer.android.com/google/play/requirements/target-sdk>
